# 🚗 Simple Parking Lot Management System

## 📌 Project Overview
The **Simple Parking Lot Management System** is a console-based application developed using C++. It helps manage vehicle parking operations efficiently using Object-Oriented Programming (OOP) concepts.

This project is developed as a B.Tech Information Technology mini project to demonstrate practical implementation of C++ programming.

## ✨ Features
- Park a Vehicle (Car/Bike)
- Display All Parked Vehicles
- Vehicle Exit Management
- Automatic Parking Fee Calculation
- Available Parking Slot Display
- Parking History Management
- File Handling for Data Storage
- Input Validation and Error Handling

## 🛠️ Technologies Used
- **Language:** C++
- **Concepts:** Object-Oriented Programming (OOP)
- Classes and Objects
- Encapsulation
- Constructors
- File Handling
- Exception Handling

## 💰 Parking Charges
| Vehicle Type | Charge |
|---|---:|
| Bike | ₹15/hour |
| Car | ₹30/hour |

**Total Parking Capacity:** 10 Vehicles

## ▶️ How to Run the Project

### Compile
```bash
g++ -std=c++11 parking.cpp -o parking
```

### Run
```bash
./parking
```

For Windows:
```bash
parking.exe
```

- To manage vehicle entry and exit records.
- To calculate parking fees automatically.
